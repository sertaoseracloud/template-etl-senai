## Phase 5: Event Trigger & Local Simulation

**Goal:** Job accepts file parameter, local trigger simulation works in Floci, Terraform provisions EventBridge infrastructure.

### Requirements
- EVT-01: Glue job aceita parametro de arquivo
- EVT-02: Job registra no CloudWatch o arquivo processado
- EVT-03: Terraform provisiona regra EventBridge
- EVT-04: EventBridge target e o Glue Job
- EVT-05: IAM policy permite EventBridge invocar Glue Job
- SIM-01: `./run.sh upload <file>` faz upload para S3
- SIM-02: `./run.sh watch` detecta novos arquivos
- SIM-03: Fluxo completo validavel localmente
- SIM-04: Documentacao do trigger real

### Plans

## Phase 6: Performance Testing

**Goal:** Dynamic test data generator creates configurable datasets, performance tests measure throughput and log structured JSON results.

### Requirements
- PERF-01: Script generates CSV with configurable rows
- PERF-02: Supports --rows, --output, --schema
- PERF-03: `./run.sh perf-test <n_rows>` runs full pipeline
- PERF-04: Logs execution time and throughput
- PERF-05: Results in structured JSON format
- EVT-03/04/05: EventBridge infrastructure validated

### Plans
- 06-01: Performance Testing Infrastructure
