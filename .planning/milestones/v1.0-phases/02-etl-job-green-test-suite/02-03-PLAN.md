    `athena_query(sql: str) -> list[dict]` — runs a query against the Floci Athena endpoint using
    boto3. The Floci Athena API supports StartQueryExecution + GetQueryExecution + GetQueryResults.
    Use the Glue client for the catalog operations and a separate boto3 client for Athena.

    Build the Athena client with: `boto3.client("athena", endpoint_url=endpoint_url())`.

    ```python
    def athena_query(sql: str) -> list[dict]:
        client = boto3.client("athena", endpoint_url=endpoint_url())
        response = client.start_query_execution(
            QueryString=sql,
            QueryExecutionContext={"Database": database_name()},
            ResultConfiguration={"OutputLocation": f"s3://{curated_bucket()}/athena-results/"}
        )
        query_id = response["QueryExecutionId"]
        # Poll until complete
        for _ in range(60):  # up to 60 seconds
            result = client.get_query_execution(QueryExecutionId=query_id)
            state = result["QueryExecution"]["Status"]["State"]
            if state == "SUCCEEDED":
                break
            elif state == "FAILED":
                raise RuntimeError(f"Athena query failed: {result['QueryExecution']['Status']['StateChangeReason']}")
            time.sleep(1)
        else:
            raise RuntimeError(f"Athena query timed out after 60 seconds: {query_id}")
        # Fetch results
        results = client.get_query_results(QueryExecutionId=query_id)
        columns = [col["Label"] for col in results["ResultSet"]["ResultSetMetadata"]["ColumnInfo"]]
        rows = []
        for row in results["ResultSet"]["Rows"][1:]:  # skip header row
            rows.append(dict(zip(columns, [cell["VarCharValue"] for cell in row["Data"]])))
        return rows
    ```

    Note: The OutputLocation must be a writeable S3 path. Create the athena-results/ prefix
    directory if it does not exist (use s3.put_object with an empty body and ContentLength=0, or
    rely on Athena to create it). If Athena returns AccessDenied, create the prefix first.
