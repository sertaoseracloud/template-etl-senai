Create .github/workflows/ci.yml with three sequential jobs per D-05:

## Job: lint
Runs first for fast feedback.
- Uses: docker/build-push-action for Glue image cache (D-01)
- Runs: ./run.sh lint (invokes ./run.sh lint, not duplicate compose/ruff commands — CI-02)
- Pulls Python slim image with ruff pre-installed, runs ruff check and format check

## Job: terraform (depends on: lint)
- Runs: terraform init -backend=false, terraform fmt -check -recursive, terraform validate
- No AWS credentials needed (offline validation per IAC-04)
- Must pass for job to succeed

## Job: test (depends on: terraform)
- Uses: docker/build-push-action for Glue image cache (D-01, cache-from: type=gha, cache-to: type=gha,mode=max)
- Runs: ./run.sh bootstrap && ./run.sh seed && ./run.sh job && ./run.sh test
- Invokes ./run.sh subcommands, not duplicate compose steps (CI-02)
- The full pipeline: up environment → populate catalog → seed data → run job → run tests

## Workflow triggers
- on: push (to main branch)
- on: pull_request (all branches)

## Glue image caching (D-01)
Use docker/build-push-action with:
- cache-from: type=gha
- cache-to: type=gha,mode=max

This caches the ~4.77 GB Glue image between runs.
Cache small dependencies (ruff, pytest, boto3) via actions/cache standard.

## Credentials
Use AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY from repository secrets.
Document in the workflow that OIDC is deferred to v2 (deferred in 03-CONTEXT.md deferred ideas).
