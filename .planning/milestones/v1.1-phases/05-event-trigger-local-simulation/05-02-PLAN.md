       }
       variable "raw_bucket_name" {
         description = "S3 raw bucket name"
         type        = string
       }

       }
       variable "prefix" {
         description = "S3 key prefix to watch (e.g., temperaturas/)"
         type        = string

       }

    2. terraform/modules/eventbridge/main.tf:
       - `aws_cloudwatch_event_rule.s3_object_created`: EventBridge rule with event_pattern for S3 ObjectCreated via CloudTrail
         ```hcl
         event_pattern = jsonencode({
           source : ["aws.s3"],
           "detail-type" : ["AWS API Call via CloudTrail"],
           detail : {
             eventSource : ["aws.s3"],
             eventName : ["PutObject", "CompleteMultipartUpload"],
             requestParameters : {
               bucketName : [var.raw_bucket_name]
             }
           }
         })
         ```
         Note: S3 ObjectCreated events arrive via CloudTrail, so detail-type must be "AWS API Call via CloudTrail" and eventName filters for PutObject/CompleteMultipartUpload.
       - `aws_iam_role.eventbridge_to_glue`: IAM role with events.amazonaws.com trust policy
       - `aws_iam_role_policy.eventbridge_glue_invoke`: Policy allowing glue:StartJobRun on the specific job ARN
       - `aws_cloudwatch_event_target.glue_job`: Target with input_transformer:
         ```hcl
         input_transformer {
           input_template = "\"--file-key\", \"<s3-key>\""
           input_paths = {
             "s3-key" = "$.detail.requestParameters.key"
           }
         }
         ```
         Note: StartJobRun expects job arguments as comma-separated "--param", "value" format, not JSON. The s3-key path extracts from CloudTrail's requestParameters.key.
       - `aws_s3_bucket_notification.to_eventbridge`: Enable S3 to send events to EventBridge

    3. terraform/modules/eventbridge/outputs.tf:
       ```hcl
       output "eventbridge_role_arn" {
         value = aws_iam_role.eventbridge_to_glue.arn
       }
       ```

    4. terraform/modules/glue-job/variables.tf: Add optional `--file-key` default argument variable

    5. terraform/main.tf: Add module "eventbridge" block connecting to glue-job module

| S3 -> EventBridge | S3 bucket notification delivering events to EventBridge |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Information Disclosure | EventBridge receives all CloudTrail S3 events | low | mitigate | Event pattern filters by eventName (PutObject/CompleteMultipartUpload) and bucket name to limit scope |
| T-05-05 | Elevation of Privilege | Overly permissive EventBridge IAM | medium | mitigate | Policy restricts glue:StartJobRun to specific job ARN only (least privilege) |
| T-05-06 | Tampering | Input Transformer injection | low | accept | Input Transformer extracts from AWS CloudTrail event structure, not user input |
| T-05-07 | Information Disclosure | CloudTrail events may contain sensitive request metadata | low | accept | Event pattern only extracts key path; IAM role scoped to specific job ARN |
