Outputs: glue_job_name, iam_role_arn, raw_bucket_name, curated_bucket_name, glue_database_name, glue_table_name

## terraform/main.tf
Root module calls all four sub-modules. Uses local values for derived names (apply name transforms here, matching config.py). Passes all required values to child modules.

## terraform/modules/glue-job/
Creates aws_glue_job resource. Points job to s3a path using curated bucket + location. Uses the Python script path matching the repo structure (jobs/csv_to_parquet/job.py as the --script argument).

## terraform/modules/iam-role/
Creates aws_iam_role (Glue Service Role) and aws_iam_role_policy_attachment.
Policy (policy.tf): least-privilege per D-11:
- s3:GetObject, s3:PutObject on both buckets
- s3:ListBucket on both buckets
- logs:CreateLogGroup, logs:CreateLogStream, logs:PutLogEvents
- glue:GetTable, glue:GetPartitions, glue:CreatePartition
No wildcard actions. Resources use ARNs constructed from variables (not hardcoded).

## terraform/modules/s3-buckets/
Creates two aws_s3_bucket resources: raw and curated. Adds bucket ownership assertions and optional public-access-block.

## terraform/modules/catalog-table/
Creates aws_glue_catalog_database and aws_glue_catalog_table.
Reads schema via: jsondecode(file("../catalog/schema/temperaturas.json")) (D-06, CAT-03).
Maps neutral schema to Glue API inputs (replicate bootstrap.py build_table_input logic).
Creates aws_glue_partition resources in a count-based loop over schema["partitions"].
Must handle 18 partitions (3 dates x 6 cities) per the updated schema.
