## Design Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| D-01 | Ports recebem dict, não DataFrame | Domain testável sem Spark |
| D-02 | Factory pattern para DI | Explícito, sem mágica |
| D-03 | Exceptions para erros | Pythonic, simples |
| D-04 | Adapters convertem dict ↔ DataFrame | Separação de concerns |

## Must-Haves

1. **Domain sem Spark**: Nenhum import pyspark, awsglue, boto3
2. **Ports como ABC**: JobPort, StoragePort, TransformPort com @abstractmethod
3. **job.py < 50 lines**: Apenas orchestration, não lógica
4. **transforms/ mantido**: Não mexer em transforms/csv_to_parquet.py
5. **Backward compatible**: CLI interface unchanged

## Contract: StoragePort

```python
class StoragePort(ABC):
    @abstractmethod
    def read_csv(self, path: str) -> list[dict]: ...
    
    @abstractmethod
    def write_parquet(self, data: list[dict], path: str, partition_cols: list[str]) -> None: ...
```

## Contract: TransformPort

```python
class TransformPort(ABC):
    @abstractmethod
    def add_city_key(self, data: list[dict]) -> list[dict]: ...
    
    @abstractmethod
    def derive_temp_media(self, data: list[dict]) -> list[dict]: ...
```

## Contract: JobPort

```python
class JobPort(ABC):
    @abstractmethod
    def run(self, request: JobRequest) -> JobResponse: ...
```
