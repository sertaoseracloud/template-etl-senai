# Plan: Phase 03 - Integration & Performance Tests

## User Story
**As a** developer **I want to** run integration tests with S3 fixtures and real PySpark tests **so that** I can validate the hexagonal architecture end-to-end and ensure the job works correctly before deployment.

## Objective
Complete deferred integration tests from Phase 2 and add performance testing infrastructure.

**Purpose:** Validate that the hexagonal architecture wiring (GlueAdapter -> UseCase -> SparkAdapter) works end-to-end with the Floci S3 emulator.

**Output:**
- `tests/integration/test_adapters/` with S3 fixture and adapter tests
- `tests/integration/test_spark_real.py` with real PySpark tests
- `.pre-commit-config.yaml` for DX-01.3
- `.github/workflows/ci.yml` for CI/CD stub

---

## Context

**Project:** `template_etl` - AWS Glue 5.0 ETL with Hexagonal Architecture

**Existing Integration Tests:** `tests/integration/test_job.py` runs the full job via subprocess spark-submit. This plan adds adapter-level integration tests.

**Architecture:**
```
jobs/csv_to_parquet/
├── domain/entities.py (CsvRecord, JobResult, JobStatus)
├── domain/ports/ (StoragePort, TransformPort, JobPort)
├── application/use_cases.py (ProcessCsvUseCase)
├── adapters/primary/glue_adapter.py (GlueAdapter)
├── adapters/secondary/spark_adapter.py (SparkAdapter)
└── infrastructure/di.py (DIContainer)
```

**Floci S3 Emulator:** `http://localhost:4566` (via docker compose)
