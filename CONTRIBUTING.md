# Contributing

## Maintenance Boundary

This repository is a **template**. Its purpose is to be cloned, adapted, and extended
by each adopter for their own project. The scope of what belongs in this repository
is intentionally narrow.

### In scope

Pull requests that improve the scaffolding:

- `./run.sh` and its subcommand surface
- Tests and test infrastructure
- Terraform module
- Documentation (README, this file, issue templates)
- CI/CD workflows

### Out of scope

Pull requests that elaborate the sample job's business logic — the temperature
transformation, the sample dataset, or any pipeline-specific logic. Those changes
belong in your own project, not in the template.
